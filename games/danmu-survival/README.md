# 弹幕求生·末日三十天

COD 同人 · 末日生存。穿越女主靠**真假掺半的弹幕**当金手指，末日前 30 天囤货求生；
末日后前往大基地，靠**实力**赢得 141 群像的信任（乙女多线）。纯前端，可整体拖入 Ura 的 `games/`。

## 当前版本 v0.2（Ura 接入 + 第二阶段硬机制雏形）
已实现：
- **状态机**：标题 → 选异能 → 游戏 → 结算/死亡
- **弹幕渲染层**：浮在画面上的滚动弹幕（还原酒馆「文中弹幕」，可配字号/速度/密度/透明度；`鉴弹之眼`异能可显示真/假标记）
- **6 异能**开局选择（Lv1，含被动：空间仓库 +60 空间、造物之手每日产出、鉴弹之眼揭示真假）
- **每日循环**：3 行动点 → 打工 / 基金 / 线下采购 / 网购 → 推进到下一天
- **4 物资线**（水/食/药/防身）+ 现金 + 储物空间约束
- **每日消耗**水粮，**5 死亡线**之渴死/饿死/穷死已接入
- **30 天事件**（部分）按时间窗口随机触发，投放真🟢/假🔴弹幕
- **API 接入**：直接复用 Ura 主页全局 `LW_API_URL / LW_API_KEY / LW_API_MODEL`
- **第二阶段雏形**：AI 剧情 GM + 晶核成长 + 跑团战斗（等级×10 + d20）+ 基地防御/补给/信任
- **硬机制**：末日后每若干回合推进天数，野外消耗水粮，基地消耗补给，尸潮压力到期触发防线检定
- **收音机线**：捡到/修好收音机后，报纸入口切换为幸存者电波，投放基地、尸潮和 141 线索

## 运行
直接用浏览器打开 `index.html` 即可（无需服务器）。

## 接入 Ura
把整个 `danmu-survival/` 文件夹放进 `games/`，在主页面 `manifest.json` 注册即可。
AI 调用只读取全局 `LW_API_URL / LW_API_KEY / LW_API_MODEL`；如需改接口，请回到 Ura 主页「设置 API」。
