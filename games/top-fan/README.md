# 头号粉丝 · TOP FAN

明星养成 × COD 大兵饭圈暗恋。台前你是从海选冲向成团出道的练习生；
台后，你超话里那些各司其职的神仙粉——站姐、数据、反黑、氪金、做娃、画手……
其实是一支被组织起来的特遣队。他们隔着屏幕先沦陷，而你还不知道。

## 玩法（第一阶段 · 爱豆选秀）

- **开局捏人**：身份三选一（爱豆可玩 / 歌星 · 影星留接口）、艺名 / 年龄 / 粉丝团名 / 超话名、20 点自由分配到 6 属性（唱 / 跳 / Rap / 颜值 / 体力 / 舞台魅力）。
- **每周循环**：训练期分配行动点（练唱跳rap / 形象 / 营业发博 / 休息）→ 上台公演。
- **公演**：按属性 Roll 点（完美 / 优秀 / 出糗），直播弹幕实时滚（混着男主定位口吻），导师定担当 + ABCDF 评级，生成排行榜（名次 / 前后对手 / 票差）。
- **压力 / 生病**：高强度训练涨压力，爆表生病——触发照顾型男主关怀事件。
- **男主隐藏加成**：在场男主的打投 / 控评 / 氪金，暗中给你涨票，你只看到"来路不明的票"。
- **6 场公演** → 成团出道夜见分晓。

## 微博（本作灵魂）

- **广场**：男主各自"定位"的博文 + 路人粉 + 你的营业博。
- **超话等级榜**：每个男主马甲号的等级 = 他对你的**暗恋值可视化**，看着他一级级沦陷。
- **热搜**：你的词条 / CP / 黑热搜（黑热搜带来压力）。
- **粉丝群**：围观男主们配合得像一支队伍。
- **破屏①**：超话里暗恋值够高时点他，"认出"马甲号背后的人 → 解锁**私信私聊**（接 AI）。
