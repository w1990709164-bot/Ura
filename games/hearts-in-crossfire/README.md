# 《交火心跳：21日》第一版原型

直接双击 `index.html` 即可开始游戏，无需安装依赖。

当前版本包括：

- 成年确认与核心女嘉宾自定义
- 职业、专长、短板、隐藏面设定
- 六位男嘉宾档案与独立关系状态
- Day 1 精写入住序章、落座、晚餐与匿名心动短信
- Day 2～21 AI导演循环：晨间、主题活动、自由行动、晚间交锋
- 21天固定节目骨架与动态角色组合
- Day 2～21每个时段均有具体节目分镜，包含采购、挑战、旅行、秘密房间、停电、召回、坦白夜与最终告白
- 独立任务卡、节目组通知、男嘉宾未播单采和观察室模块
- 结构化关系影响、关键记忆、每日日志与跨日推进
- AI不可用时明确显示错误并暂停推进，由玩家手动重新生成
- 六名男嘉宾之间的兼容/竞争关系与多人结局门槛
- 单人、双/三人隐藏路线、规则之外与独自离开结局
- 三个月后采访、二周目与成就继承
- 三个手动存档槽和JSON存档导入/导出
- 可随时调整的亲密内容等级和内容雷区
- 成就系统与本地自动存档
- 手机端响应式界面
- 可选 OpenAI 兼容接口自由输入（默认 `http://127.0.0.1:7897/v1`）

API 设置保存在浏览器本地，不会写入游戏文件。部分接口可能不允许浏览器跨域访问；正式版本建议增加本地或云端代理服务。

清除存档：进入游戏后点击右上角 `•••`，选择“清除存档”。


## 里世界整合说明

本版本已并入 `里世界` 游戏合集，入口为：`games/hearts-in-crossfire/index.html`。
API 不再在本游戏内单独配置，统一读取首页 `index.html` 保存的：

- `LW_API_URL`
- `LW_API_KEY`
- `LW_API_MODEL`

请先回到里世界首页点击“设置 API”，再进入本游戏。

## 连续场景整合版

- 预设选项与自由输入同权：任一方式成功后都会结算当前时段，旧选项不会再次出现。
- 每个时段支持最多三轮继续互动，玩家确认后才进入下一节目环节。
- 锁定每日搭档、分组、约会对象、地点和胜负结果，后续提示词必须遵守。
- 新时段必须描写离开旧地点、移动或时间流逝，避免超市直接跳厨房。
- 玩家职业与专长有冷却，不再每幕机械成为核心。
- 新增节目中心：日程、单采申请、朋友圈、匿名谈心、主动邀约、事实核对和规则拒绝。
- 每晚要求 AI 生成六封匿名短信与六条嘉宾朋友圈，缺失会明确提示重新生成。
- 记录昨晚短信与次日互动，被忽略的角色才可能在合适场景产生克制醋意。
- 演播室可由 Soap、Gaz、Price、Hesh、Horangi 等熟人担任观察嘉宾。
